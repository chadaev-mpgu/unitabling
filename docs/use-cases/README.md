# Юз-кейсы

Актор: **методист учебного подразделения** (единственный пользователь в MVP,
аутентификации нет).

## Сценарии

| Файл | Сценарии |
|---|---|
| [`00-projects.md`](00-projects.md) | Создание и выбор проекта |
| [`01-layout-and-calendar.md`](01-layout-and-calendar.md) | Разметка дня, разметка недели, академический календарь, праздники |
| [`02-dictionaries.md`](02-dictionaries.md) | Преподаватели, аудитории, группы; дисциплины (через БД) |
| [`03-teaching-loads.md`](03-teaching-loads.md) | Строки учебной нагрузки: создание, просмотр, фильтры, правка, удаление |
| [`04-scheduling.md`](04-scheduling.md) | Расстановка занятий в сетку: drag-and-drop, конфликты, чётность |
| [`05-flows.md`](05-flows.md) | Потоки: слияние строк из таблицы и из сетки, подмножества, разбор |

Общие правила, на которые опираются все сценарии:
- глобальные данные (разметка, календарь, справочники) общие на все проекты
  и редактируются только на своих экранах — проект ссылается на них read-only;
- прошедшие вхождения уроков неизменяемы и не удаляемы;
- конфликты severity `error` блокируют сохранение урока,
  severity `warning` — нет.
