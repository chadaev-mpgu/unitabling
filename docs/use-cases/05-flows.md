# Сценарии: потоки

**Поток** — НЕ отдельная сущность. Поток = строка нагрузки
с несколькими группами, создаваемая слиянием per-group строк.
Полные правила слияния — в этом файле (UC-5.1, UC-5.2).

## UC-5.1. Объединить строки в поток из таблицы нагрузки

**Шаги:**
1. Методист выделяет две и более строки нагрузки.
2. Запускает объединение. Проверки:
   - одинаковые дисциплина и lessonType;
   - преподаватели совпадают, либо один из них не назначен
     (поток берёт назначенного); два разных назначенных преподавателя
     — объединение блокируется.
3. В диалоге задаёт часы потока (по умолчанию — минимальное из «остатков»
   выбранных строк; остаток = `hoursTotal − hoursScheduled`).
4. Сохраняет.

**Результат:**
- создаётся строка-поток: `groupIds` = все группы выбранных строк,
  `hoursTotal` = заданные часы;
- часы потока вычитаются из каждой исходной строки
  (`hoursTotal −=` часы потока);
- исходная строка **удаляется**, только если после вычитания в ней
  нет ни одного Lesson; иначе остаётся с уменьшенным остатком
  (история и проведённые часы сохраняются);
- если остатки у групп были разные — часы потока = min, превышение
  остаётся на собственных строках групп.

## UC-5.2. Объединить в поток при перетаскивании в сетку

**Ситуация.** В слоте стоит урок строки A (группа A, дисциплина X,
тип T, преподаватель Y). Методист перетаскивает строку B
(группа B, та же X, T, Y) на этот слот и выбирает
«Объединить в поток».

**Результат:**
- создаётся строка-поток из A и B; часы потока = min(остаток A, остаток B);
  часы вычитаются из обеих исходных строк (по правилу UC-5.1);
- целевый урок перепривязывается на строку-поток;
- если часть целевого урока уже в прошлом:
  - **прошедшая часть** остаётся на строке A с прежним составом групп;
  - **будущая часть** перепривязывается на поток (по timestamp, та же
    механика, что и блокировка прошедших недель);
  - группа B **не получает часов** за прошедшие недели;
- groupIds урока из строки-потока = все группы потока.

## UC-5.3. Расставить урок из строки-потока

Урок из строки-потока расставляется **целиком**: `Lesson.groupIds` =
все группы потока, часы идут каждой группе. В `Lesson.groupIds`
записывается снимок состава на момент создания (аналог `teacherId`).

## UC-5.4. Подмножества потока

Если нужно, чтобы часть часов группы шла отдельно от потока, эти часы
**заранее не отправляются в поток**: они остаются на per-group строке
и расставляются отдельно. Ретроспективно «вырезать» подмножество
из потока нельзя.

## UC-5.5. Разбор потока

- Поток **без** уроков можно разобрать: часы возвращаются исходным
  строкам (исходные строки создаются заново, если были удалены).
- Поток, у которого **уже есть уроки**, в MVP разбирать нельзя.
  Вырезание расставленного хвоста с перераспределением часов —
  в `../future/improvements.md`.

## Учёт часов по группам

Во «виде по группе» таблицы нагрузки суммы остатков/расставленных/
проведённых часов считаются по всем строкам, содержащим эту группу
(включая потоки) — составная картина «своих + потоковых» часов
одной группы.
