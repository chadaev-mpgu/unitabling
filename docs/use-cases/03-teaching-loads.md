# Сценарии: учебная нагрузка

Учебная нагрузка — «задача на расстановку»: обязательное промежуточное звено
между учебным планом и занятиями. Строки принадлежат **проекту**
(глобальными являются только справочники и разметка).

## UC-3.1. Создать строку нагрузки

**Шаги:**
1. Методист выбирает дисциплину (из read-only справочника), группу,
   тип занятия (`Lecture | Seminar | Lab | Exam | Credit`) и вводит
   `hoursTotal` (шаг 0,5 часа).
2. Преподаватель — опционально; при необходимости назначается до
   или во время установки в сетку.
3. Строка сохраняется.

**Правила:**
- строки создаются в разрезе группы: **одна строка = одна группа**,
  свои часы;
- допускаются несколько строк с одинаковыми (дисциплина, группа, lessonType)
  — это независимые «партии» часов (например, с разными преподавателями).

## UC-3.2. Просмотр таблицы нагрузки

- таблица строк с **совмещаемыми фильтрами**: группа, преподаватель,
  дисциплина, тип занятия;
- во «виде по группе» часы (остаток / расставленные / проведённые)
  суммируются по всем строкам, содержащим эту группу — включая потоки;
- строка-поток отображается с внутренним блоком (чуть другой фон):
  список групп и пометка «поток»; обычная строка — без
  дополнительного содержимого.

## UC-3.3. Правка строки

После создания методист может менять **только назначенного преподавателя**.
Дисциплина, группа, тип и часы неизменяемы; смена состава групп —
только через слияние (см. `05-flows.md`).

## UC-3.4. Удаление строки

Удаление допустимо **только если на строку не ссылается ни один Lesson**.
Иначе строка остаётся (история и проведённые часы сохраняются),
в том числе при нулевом остатке.

## Производные величины

| Величина | Как считается |
|---|---|
| `hoursScheduled` | сумма часов вхождений всех Lesson строки, вхождения которых существуют (см. `data-model/time-mechanics.md`) |
| `hoursConducted` | то же, но только за прошедшие вхождения (по timestamp) |
| **остаток** | `hoursTotal − hoursScheduled` |

Экран слияния в поток и сетка используют остаток как доступный ресурс
строки.
