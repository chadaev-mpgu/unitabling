# Сценарии: проекты

## UC-0.1. Создать проект

**Описание.** Проект = одно расписание за один период для всех групп
факультета/института (например, "ИФТИС-2-осень-2026"). Курс, семестр и год
закодированы в имени проекта; отдельных полей для периода нет — проект
использует данные календаря только для чтения.

**Шаги:**
1. Методист вводит имя проекта.
2. Выбирает академический календарь (глобальный, может быть на год
   или на семестр — на усмотрение методиста).
3. Сохраняет. Создаётся проект с пустыми `loads` и `lessons`.

**Результат.** Проект ссылается на календарь через `calendarId`;
глобальные данные (разметку, справочники) в проект НЕ копируются.

## UC-0.2. Открыть проект

**Описание.** Выбор существующего проекта для работы: сетка расписания,
нагрузка, конфликты относятся к выбранному проекту.

> **Примечание.** Экран управления проектами (список/создание) явно не
> указан в списке экранов MVP, но принят как обязательный базовый
> сценарий (по решению в чате).
