# Сценарии: справочники

Преподаватели, аудитории и группы — глобальные справочники, общие на все
проекты. Проект ссылается на них read-only.

## UC-2.1. Преподаватели (Teachers)

CRUD: создание, просмотр, редактирование, удаление.
- поля: `fullName`, `position?` (должность);
- **нельзя удалить** преподавателя, на которого ссылается хотя бы одна
  нагрузка или урок (в любом проекте) — только редактировать.

## UC-2.2. Аудитории (Rooms)

CRUD.
- поля: `name`, `capacity`, `kind` (`lecture | lab | computer | gym | other`);
- `capacity` используется конфликтом `RoomCapacity`
  (суммарная численность групп занятия > вместимость → warning);
- редактирование `capacity` меняет расчёт предупреждений на лету
  (конфликты не хранятся);
- аудитория в употреблении (ссылки из уроков) — удалить нельзя.

## UC-2.3. Группы (StudentGroup)

CRUD.
- поля: `name` (например, "ИПИ-21-1"), `size`, `courseYear?`, `admissionYear?`;
- `size` участвует в расчёте `RoomCapacity`;
- группа в употреблении (ссылки из нагрузок/уроков) — удалить нельзя.

## UC-2.4. Дисциплины (Discipline)

- глобальный **read-only** справочник («Математический анализ», «Информатика»);
- в MVP **экрана управления нет**: дисциплины загружаются администратором
  напрямую в БД;
- `color` — случайный, если не назначен при создании.
