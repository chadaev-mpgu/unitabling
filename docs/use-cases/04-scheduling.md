# Сценарии: сетка расписания (LessonSchedule)

Сетка проекта: недели × дни × слоты. Клетка = (неделя, weekday, slotIndex).
Боковая панель — строки учебной нагрузки проекта (обычные и потоки;
у потоков внутренний блок со списком групп и пометкой «поток»).

## Режимы просмотра

**Виды:** «по группе», «по преподавателю», «по аудитории». Вид — строгий
фильтр: в сетке остаются только занятия выбранной сущности (для группы — все,
где группа входит в состав урока, включая потоки; для преподавателя — с этим
преподавателем; для аудитории — в этой аудитории).

- Пока сущность не выбрана, сетка не показывается: вместо неё подсказка
  «Выберите группу, преподавателя или аудиторию…», панель нагрузки — все
  строки проекта. Выбор запоминается по каждому виду отдельно.
- Панель «Текущая нагрузка» синхронна виду: по группе — строки, содержащие
  группу (включая потоки); по преподавателю — его строки; по аудитории — все
  строки (в нагрузке нет аудитории), а дроп подставляет выбранную аудиторию
  в диалог занятия.

**Период — пара недель** (числитель/знаменатель): 1–2, 3–4, …; при нечётном
числе недель последний период — одна неделя. В клетке верхняя половина —
нечётная неделя пары, нижняя — чётная; показываются только вхождения недель
периода (`weekRange` + парность). Период — вьюпорт, а не диапазон создания:
новый урок по умолчанию ставится на все недели календаря (UC-4.1).

Ограничение MVP: разметка дня/недели и праздники в сетку не подключены,
поэтому период не дробится праздниками и override'ами — учтём при
подключении разметки.

## UC-4.1. Поставить урок в свободный слот

**Шаги:**
1. Методист перетаскивает строку нагрузки из панели в свободную позицию
   клетки: пустая клетка целиком или свободная половина — верхняя
   (`Above`, нечётные недели) / нижняя (`Below`, чётные).
2. Если у строки не назначен преподаватель — открывается диалог
   выбора преподавателя.
3. Открывается диалог параметров урока:
   - аудитория (обязательная);
   - парность: `Above` / `Below` / `Both` — доступны только парности
     свободных половин; `Both` (вся клетка) — только пока клетка пуста;
     дроп в половину предвыбирает её парность;
   - диапазон недель `weekRange` (по умолчанию — все недели календаря;
     номера недель — с 1, `to` включительно).
4. Сохранение.

**Особые случаи:**
- **Exam / Credit** — не повторяющийся паттерн: `weekRange` всегда
  ровно одна неделя `{ from: N, to: N }`; парность не имеет значения
  (`Both`), поэтому экзамен/зачёт занимает клетку целиком и ставится
  только в пустую клетку;
- **прошедшие клетки** (вхождение уже состоялось) заблокированы:
  ставить и редактировать нельзя; прошедшая половина пары закрыта, а
  половина будущей недели остаётся доступной — началом диапазона
  (`weekRange.from`) не может быть прошедшая неделя. В такой клетке
  доступны парности будущей половины и `Both`: прошедшая неделя в
  диапазон не попадёт, а в сетке занятие с `Both` отрисуется половиной,
  пока в периоде реально проходит только одна неделя;
- если в какой-то неделе диапазона слота нет (шаблон короче,
  день выходной или праздник) — вхождение в этой неделе не существует;
  система показывает `SlotUnavailable` (warning), часы этой недели
  не учитываются.

**Валидация при сохранении:**
- блокирующие конфликты (`TeacherDoubleBooked`, `RoomDoubleBooked`,
  `GroupDoubleBooked`) — сохранение запрещено;
- предупреждения (`RoomCapacity`, `SlotUnavailable`) — показываются,
  сохранение допускается.

Правила детекции конфликтов — в `../data-model/conflicts.md`.

## UC-4.2. Поставить урок в занятый совместимый слот

При перетаскивании, кроме свободных слотов, подсвечиваются **занятые
совместимые** слоты — совместимость строгая: одинаковые
дисциплина, lessonType и преподаватель. В другие занятые слоты
перетаскивание не предлагается.

По дропу в совместимый слот система предлагает (диалог):
- **«над чертой» / «под чертой»** — отдельный урок для перетаскиваемой
  строки с противоположной парностью; доступно только если парность
  целевого урока `Above` (тогда «под чертой») или `Below` (тогда «над
  чертой»);
- **«Объединить в поток»** — создание строки-потока и перепривязка
  целевого урока (подробно — в `05-flows.md`, UC-5.2).

Если у целевого урока парность `Both`, варианты «над/под чертой»
недоступны (слот полностью занят) — только «Объединить в поток».

## UC-4.3. Изменить / удалить урок (только будущие)

Клик по уроку в сетке открывает его панель (для непрошедшего урока):
- смена аудитории, парности, диапазона недель;
- удаление — только если все вхождения урока ещё в будущем;
  проведённые часы возвращаются в нерасставленную нагрузку
  (пересчёт на лету).

Прошедшие вхождения недоступны для изменений
(см. `../data-model/time-mechanics.md`, «Дробление weekRange»).

## Просмотр конфликтов

Конфликты проекта рассчитываются на лету (не хранятся) и возвращаются
через `GET /projects/:projectId/conflicts` (предварительно; уточняется
при проектировании API). В сетке конфликтующие уроки помечаются;
сохранение урока с `error`-конфликтом блокируется.

Внизу экрана расписания — док конфликтов: счётчик и список по всем
урокам проекта, включая скрытые текущим видом; ошибки идут первыми,
предупреждения — следом. Строка дока — переход к клетке: вид
переключается на сущность конфликта (преподавателя, аудиторию или
группу), период — на неделю с конфликтом (текущий сохраняется, если
конфликт есть и в нём), клетка прокручивается в зону видимости
и подсвечивается. Список сворачивается по клику на шапку; при
отсутствии конфликтов док не показывается.

## Отрисовка урока в клетке

- в клетке максимум два занятия: `Above` — в верхней половине,
  `Below` — в нижней; `Both` занимает клетку целиком и исключает второе;
- занятие показывается в половине недели, где оно реально проходит:
  `Both` рисуется клеткой целиком, только если вхождения есть в обеих
  неделях пары; фрагмент, начинающийся с чётной недели, — в нижней половине;
- цвет — цвет дисциплины строки нагрузки;
- урок из строки-потока — со знаком «+N групп»;
- при наведении — состав групп, аудитория, диапазон недель;
- свободная позиция показывает «+»: пустая клетка — одну кнопку на всю
  клетку, полузанятая — кнопку в свободной половине;
- drop принимают только свободные позиции; занятая целиком клетка
  (обе половины или `Both`) дроп не принимает;
- занятость половины считается по занятиям вида, чьи `weekRange` пересекают
  выбранный период, — даже если в неделях периода вхождений нет: половина
  не принимает drop и карточку не показывает;
- диалог занятия считает доступные парности по тому же набору (конфликты —
  по всем урокам проекта, включая скрытые видом);
- смена преподавателя или аудитории урока может увести карточку из текущего
  вида.
