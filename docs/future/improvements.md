# Улучшения на будущее (не MVP)

Полный перечень улучшений — в этом файле, с деталями и мотивацией.

## 1. Поле `mergedFrom` у TeachingLoad

Исходные строки потока и вычтенные из них часы:
`mergedFrom?: { loadId, hours }[]`.
- мотивация: прослеживаемость — откуда взялась строка-поток,
  сколько часов откуда вычтено;
- важно для аудита, разбора потока с хвостом и отладки расчётов.

## 2. «Добавить группу в урок» без drag-and-drop

Точка входа из панели выбранного урока: список совместимых строк
нагрузки (одинаковые дисциплина, тип, преподаватель) с выбором
парности и опцией объединения в поток.
- мотивация: доступность (не все операции обязаны быть drag-ми),
  тот же диалог, что при дропе в совместимый слот, — один компонент
  и два входа.

## 3. Разбор потока с расставленным хвостом

«Вырезать хвост потока» с перераспределением часов: отделить часть
недель/часов потока и вернуть их на per-group строки (или в новый
поток меньшего состава).
- мотивация: сегодня разблокировать состав потока можно только
  до первого урока; реальные методисты будут менять состав
  потока по ходу семестра.

## 4. Удобная группировка таблицы нагрузки для слияния в потоки

Вид/группировка строк по «потенциальным» потокам: строки с одинаковыми
(дисциплина, тип, преподаватель) группируются визуально, чтобы
методист быстро находил кандидатов на объединение.
- мотивация: сейчас объединение требует ручного подбора строк
  через фильтры; группировка сокращает это к одному взгляду.
