# Документация «Конструктор расписания»

Веб-приложение для университета: инструмент методиста учебного подразделения,
который собирает расписание занятий.

**Цель:** MVP, который можно показать методисту и получить обратную связь.

**Стек:**
- Frontend: Vue 3, TypeScript, Vite, Pinia, vue-router, Tailwind CSS,
  shadcn-vue, Orval.
- Backend: NestJS, REST API, Prisma.
- Infrastructure: Docker, PostgreSQL.

Аутентификация не требуется. Интеграции с другими системами не нужны.

Эта папка — единый источник правды по дизайну продукта.

## SCOPE MVP

Обязательные экраны:

1. Разметка дня (DayPattern) — управление шаблонами дня: слоты со временем
   начала/окончания.
2. Разметка недели (WeekPattern) — управление шаблонами недели: какой шаблон
   дня используется в каждый день недели (null = выходной).
3. Академический календарь (AcademicCalendar) — разметка учебного года
   (или семестра, на усмотрение методиста): дата старта, число недель,
   шаблон недели по умолчанию, per-week overrides, праздники.
4. Сетка расписания (LessonSchedule) — сетка расписания проекта с drag-and-drop
   из боковой панели со строками учебной нагрузки. Строка-поток в панели
   отображается с внутренним блоком: список групп и пометка «поток».
   При перетаскивании, кроме свободных слотов, подсвечиваются занятые слоты,
   совместимые с перетаскиваемой строкой (одинаковые дисциплина, тип,
   преподаватель) — как цель для слияния в поток
   (см. `use-cases/05-flows.md`). Режимы просмотра — по группе / преподавателю /
   аудитории; период — пара недель «числитель/знаменатель»
   (см. `use-cases/04-scheduling.md`).
5. Учебная нагрузка (TeachingLoad) — таблица строк учебной нагрузки
   с совмещаемыми фильтрами: группа, преподаватель, дисциплина, тип занятия.
   Во «виде по группе» часы суммируются по всем строкам, содержащим эту
   группу (включая потоки). Строка-поток отображается с внутренним блоком
   (чуть другой фон): список групп и пометка «поток»; обычная строка —
   без дополнительного содержимого.
6. Преподаватели (Teachers) — справочник с возможностью изменения.
7. Аудитории (Rooms) — справочник с возможностью изменения.
8. Группы (StudentGroup) — справочник с возможностью изменения.

У дисциплин экрана управления в MVP нет: они загружаются администратором
напрямую в БД.

## Ключевые соглашения

- **НЕТ отдельного режима для заочного образования.** Заочка — это просто
  данные (мало недель, маленький weekRange), а не отдельная логика.
- **Lesson — это ПРАВИЛО, а не событие:** один урок действует на несколько
  недель через `weekRange`, даты разворачиваются на лету через
  академический календарь (см. `data-model/time-mechanics.md`).
- Три уровня абстракции времени: DayPattern («какой бывает день»),
  WeekPattern («какая бывает неделя»), AcademicCalendar («какая неделя
  какой шаблон использует»).
- Нагрузка (TeachingLoad) — обязательное промежуточное звено между
  учебным планом и занятиями, «задача на расстановку».
- Глобальные данные (разметка, календарь, справочники) общие на все
  проекты, проект ссылается на них read-only и не хранит копии
  (см. `data-model/README.md`).
- Весь продукт работает в пределах одного института/факультета —
  разделение не требуется.

## Краткий словарь

- **Урок (Lesson)** — правило: weekday + слот + парность + диапазон недель,
  разворачивается в реальные вхождения через академический календарь.
- **Вхождение** — конкретная дата/время занятия (разворачивается из урока).
  Часы и конфликты считаются по вхождениям.
- **Поток** — строка учебной нагрузки с несколькими группами,
  создаваемая слиянием per-group строк. НЕ отдельная сущность.
- **Остаток нагрузки** — `hoursTotal − hoursScheduled`.
- **Прошедшее вхождение** — вхождение, время которого уже наступило
  (по timestamp); не меняется и не удаляется.
